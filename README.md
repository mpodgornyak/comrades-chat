# Comrades Chat
## Decentralized messaging for the modern era

Comrades Chat is a decentralized messaging platform designed for the modern era, built on Java 21 + Spring Boot, Android, and Web, with censorship resistance.

## Features
- Decentralized architecture
- Censorship resistance
- Cross-platform support (Android, Web)

## Tech Stack
- Java 21
- Spring Boot
- Android
- Web (Node.js)
- Terraform

## Quick Start
1. Clone the repository:
   ```bash
   git clone https://github.com/your-repo/comrades-chat.git
   cd comrades-chat
   ```

2. Set up environment variables:
   ```bash
   cp .env.example .env
   ```

3. Run the application:
   ```bash
   docker-compose up
   ```

# Contributing to Comrades Chat

## How to Clone the Repository
1. Clone the repository:
   ```bash
   git clone https://github.com/your-repo/comrades-chat.git
   cd comrades-chat
   ```

## How to Run the Application
1. Set up environment variables:
   ```bash
   cp .env.example .env
   ```

2. Run the application:
   ```bash
   docker-compose up
   ```

## Code Style
- Follow the [Google Java Style Guide](https://google.github.io/styleguide/javaguide.html) for Java code.
- Follow the [Kotlin Style Guide](https://kotlinlang.org/docs/coding-conventions.html) for Kotlin code.
- Follow the [Node.js Style Guide](https://github.com/felixge/node-style-guide) for Node.js code.

# Правила проекта Comrades Chat

## Стек технологий
- Backend: Java 21, Spring Boot 3.3+, Gradle (Kotlin DSL)
- Frontend Android: Kotlin, Jetpack Compose
- Frontend Web: TypeScript, React
- Infrastructure: Terraform, Docker
- Database: PostgreSQL, Redis

## Стиль кода
- Отвечай кратко, без воды
- Показывай только измененные блоки кода (diff)
- Используй Java 21: records, sealed classes, pattern matching, virtual threads
- Spring Boot: конструкторная инъекция, не @Autowired на полях
- Комментарии только там, где объясняют ПОЧЕМУ, а не ЧТО

## Архитектура
- Проект независим от цензуры
- E2E шифрование обязательно - закладывай интерфейсы
- Мульти-облачность через Terraform
- API-first: контракты в папке /api

## Принципы разработки
- **YAGNI**: Не добавляй функционал "на будущее". Делай только то, что нужно для текущей задачи.
- **KISS**: Keep It Simple, Stupid. Простые решения лучше сложных.
- **DRY**: Don't Repeat Yourself, но не переусердствуй с абстракциями.

## Безопасность
- Никогда не хардкодь секреты
- Чувствительные данные через переменные окружения

## Правила для YAML и JSON
- Используй строго 2 пробела для отступов. НИКОГДА не используй табуляцию (Tab).
- Перед выводом файла мысленно проверь вложенность ключей.
- Для OpenAPI всегда выноси схемы в components/schemas, не пиши их inline внутри paths.
